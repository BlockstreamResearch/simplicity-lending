# Create an offer

The borrower publishes an offer and locks the collateral that backs it. The collateral stays locked until the offer is repaid or cancelled. The loan amount is paid out only after a lender funds the offer.

The fields are defined in [Offer parameters](../protocol/offer-parameters.md).
