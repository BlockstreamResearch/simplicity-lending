# Review an offer

A lender reads an open offer before sending principal: collateral, loan amount, fee, and term. The app also shows the loan-to-value. Those are defined in [Offer parameters](../protocol/offer-parameters.md).

Funding is a separate transaction. Reviewing an offer does not move funds.
